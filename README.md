# Simple RDB

VSCode에서 MySQL 데이터베이스를 손쉽게 관리할 수 있는 확장입니다. 복잡한 기능 대신 사용성에 집중했습니다.

## 주요 기능

- **연결 관리**: 사이드바에서 데이터베이스 연결 목록을 관리합니다. SSH 터널 연결을 지원합니다.
- **데이터 조회**: 자동 페이징으로 대용량 데이터도 부드럽게 탐색할 수 있습니다.
- **빠른 편집**: 데이터 그리드에서 셀을 바로 수정할 수 있습니다.
  - **Enum 편집**: 드롭다운으로 enum 값을 간편하게 선택할 수 있습니다.
  - **현재 시각 입력**: 클릭 한 번으로 `NOW()` 값을 넣을 수 있습니다.
  - **NULL 토글**: NULL 값을 쉽게 설정하거나 해제할 수 있습니다.
- **행 조작**: 행 추가, 복제, 삭제를 단축키와 컨텍스트 메뉴로 빠르게 할 수 있습니다.
- **일괄 수정**: 여러 행을 수정한 뒤 한 번에 커밋할 수 있습니다.
- **SQL 파일**: 쿼리를 보관할 SQL 파일을 사이드바에서 생성하고 내부 저장할 수 있습니다.
- **내보내기**: 조회한 데이터를 CSV 또는 Excel(`.xlsx`)로 복사하거나 다운로드할 수 있습니다.

## 요구사항

- VSCode 1.80 이상
- MySQL 5.7 이상 (추후 다른 RDB 지원 예정)

## 사용 방법

### 연결 추가하기

1. Simple RDB 사이드바에서 `+` 아이콘을 클릭합니다.
2. 호스트, 포트, 사용자, 비밀번호, 데이터베이스 정보를 입력합니다.
3. 필요시 SSH 터널을 활성화하고 SSH 호스트, 포트, 사용자, 키/비밀번호를 설정합니다.
4. **연결**을 클릭합니다.

### 데이터 조회하기

- 사이드바에서 연결 → 데이터베이스 → 테이블을 펼치면 데이터를 불러옵니다.
- 스크롤할 때마다 자동으로 다음 페이지를 가져옵니다.

### 데이터 편집하기

- 셀을 더블클릭하면 바로 편집할 수 있습니다.
- 셀 우클릭으로 NULL 설정, NOW() 입력, 값 복사 등의 빠른 동작을 사용할 수 있습니다.
- Enum 컬럼은 드롭다운으로 값을 선택할 수 있습니다.
- 모든 편집이 끝나면 **변경사항 적용** 버튼으로 한 번에 커밋합니다.

### 행 조작하기

- **행 추가**: 데이터 그리드 하단의 `+` 버튼을 클릭합니다.
- **행 복제**: 행을 우클릭 → 복제를 선택합니다.
- **행 삭제**: 행을 우클릭 → 삭제, 또는 `Delete` 키를 누릅니다.

### 데이터 내보내기

- 데이터 뷰 툴바에서 **내보내기**를 클릭합니다.
- CSV 또는 Excel 형식을 선택합니다.
- 클립보드에 복사하거나 파일로 다운로드할 수 있습니다.

### SQL 파일

- 사이드바에서 `.sql` 파일을 생성하여 쿼리를 작성하고 저장할 수 있습니다.
- 파일은 내부 저장소에 보관되며 VSCode 세션 간에도 유지됩니다.

## 기술 스택

- TypeScript
- Prettier (코드 포맷팅)

## 개발

```bash
# 의존성 설치
npm install

# 빌드
npm run compile

# Watch 모드
npm run watch

# 포맷팅
npm run format

# 확장 개발 실행
# VSCode에서 F5를 누르면 Extension Development Host가 실행됩니다.
```
