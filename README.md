# Simple RDB

VSCode에서 MySQL 데이터베이스를 손쉽게 관리할 수 있는 확장입니다. 복잡한 기능 대신 사용성에 집중했습니다.

## 주요 기능

- **연결 관리**: 사이드바에서 데이터베이스 연결 목록을 관리합니다. SSH 터널 연결을 지원합니다. 비밀번호는 VS Code SecretStorage(암호화)에 안전하게 저장됩니다.
- **데이터 조회**: 테이블을 페이지 단위로 조회합니다(Previous/Next). LIMIT이 없는 SELECT에는 자동으로 LIMIT이 적용되어 대용량 결과에서도 안정적입니다.
- **빠른 편집**: 데이터 그리드에서 셀을 바로 수정할 수 있습니다.
  - **Enum 편집**: 드롭다운으로 enum 값을 간편하게 선택할 수 있습니다.
  - **현재 시각 입력**: 클릭 한 번으로 `NOW()` 값을 넣을 수 있습니다.
  - **NULL 토글**: NULL 값을 쉽게 설정할 수 있습니다.
- **행 조작**: 행 추가, 복제, 삭제를 단축키와 컨텍스트 메뉴로 빠르게 할 수 있습니다.
- **일괄 수정**: 여러 행을 수정한 뒤 한 번에 커밋할 수 있습니다.
- **SQL 실행**: `.sql` 파일에서 `Cmd/Ctrl+Enter`로 커서 위치의 문장(또는 선택 영역)을 실행하고, 결과를 그리드로 확인합니다.
- **쿼리 자동완성**: SQL 작성 시 database / table / column을 자동완성합니다. `.` 입력 또는 `Ctrl+Space`로 실행합니다.
  - Simple RDB가 관리하는 `.sql` 파일에서 해당 파일의 연결이 활성화된 경우에만 동작합니다.
  - `FROM db.`, `alias.`, `db.table.` 한정 입력과 JOIN alias를 인식하고, 컬럼에는 타입·PK·NULLABLE 정보를 표시합니다.
  - 메타데이터는 짧은 TTL로 캐시되며, 트리 **Refresh** 시 갱신됩니다.
- **내보내기**: 조회한 데이터를 CSV / JSON / Markdown / Excel 호환(HTML) 형식으로 다운로드하거나, 선택 영역을 클립보드로 복사할 수 있습니다.

## 요구사항

## 사용 방법

### 연결 추가하기

1. Simple RDB 사이드바에서 `+` 아이콘을 클릭합니다.
2. 호스트, 포트, 사용자, 비밀번호, 데이터베이스 정보를 입력합니다.
3. 필요시 SSH 터널을 활성화하고 SSH 호스트, 포트, 사용자, 비밀번호 또는 개인키 경로/passphrase를 설정합니다.
4. **연결**을 클릭합니다.

### 데이터 조회하기

- 사이드바에서 연결 → 데이터베이스 → 테이블을 펼치면 데이터를 불러옵니다.
- 하단의 **Previous / Next** 버튼으로 페이지를 이동합니다.

### 쿼리 실행하기

- 사이드바에서 연결을 우클릭하거나 `SQL Files` 그룹에서 `.sql` 파일을 만들어 쿼리를 작성합니다.
- 에디터에서 `Cmd+Enter`(또는 `Ctrl+Enter`)를 누르면 커서가 위치한 문장이 실행됩니다. 여러 문장을 선택하면 순차 실행됩니다.
- 편집 가능한 단일 테이블 SELECT 결과는 그리드에서 바로 수정할 수 있습니다.

### 데이터 편집하기

- 셀을 더블클릭하면 바로 편집할 수 있습니다(BLOB/JSON 등 이진 타입 컬럼은 편집이 제한됩니다).
- 셀 우클릭으로 NULL 설정, NOW() 입력, 값 복사 등의 빠른 동작을 사용할 수 있습니다.
- Enum 컬럼은 드롭다운으로 값을 선택할 수 있습니다.
- 모든 편집이 끝나면 **Apply Changes** 버튼으로 한 번에 커밋합니다.

### 행 조작하기

- **행 추가**: 데이터 뷰 상단 툴바의 `+ Row` 버튼을 클릭합니다.
- **행 복제**: 행을 우클릭 → Duplicate Row를 선택합니다.
- **행 삭제**: 행 번호(`#`)를 클릭해 선택한 뒤 우클릭 → Delete Row, 또는 `Delete` 키를 누릅니다.

### 데이터 내보내기

- 데이터 뷰 툴바에서 **Export**를 클릭해 CSV / JSON / Markdown / Excel 호환 형식으로 다운로드합니다.
- 셀 또는 행을 선택한 뒤 우클릭 → **Advanced Copy**로 선택 영역을 클립보드에 복사할 수 있습니다.

### SQL 파일

- 사이드바에서 `.sql` 파일을 생성하여 쿼리를 작성하고 저장할 수 있습니다.
- 파일은 사용자 홈의 내부 저장소(`~/.simpledb`)에 보관되며 VSCode 세션 간에도 유지됩니다.

## 설정

- `simpleRdb.pageSize`: 테이블 뷰의 페이지당 행 수 (기본 100)
- `simpleRdb.defaultLimit`: LIMIT 없는 SELECT에 자동 적용할 행 수 (기본 1000, 0이면 비활성화)
- `simpleRdb.maxBulkDelete`: 한 번에 삭제할 수 있는 최대 행 수 (기본 100)

npm run lint
npm test

# 프로덕션 번들
npm run bundle

# VSIX 패키징
npm run package

# 확장 개발 실행
